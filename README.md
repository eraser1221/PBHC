# PBHC
This repository contains the data and R code associated with the research paper ‘Navigating complexity with hydrological simplicity: a pragmatic key to freshwater cetacean habitat restoration’
The EnvLayer file: These raster data layers include the Vorticity Layer, Fr Layer, Speed Layer, and Depth Layer. They are all calculated and converted from shapefiles (.shp) generated by the MIKE21 FM module.
The Rcode file: R Markdown files for analysis and visualization
The data file: Processed data ready for analysis (.csv)
